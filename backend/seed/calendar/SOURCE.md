# 行政機關辦公日曆（期限試算的假日順延用）

- 來源：政府資料開放平臺資料集 14718「中華民國政府行政機關辦公日曆表」<https://data.gov.tw/dataset/14718>（行政院人事行政總處提供）。
- 下載方式：先讀資料集 API `https://data.gov.tw/api/v2/rest/dataset/14718` 取得各年檔案網址，再逐一下載；User-Agent `legaltech-calendar-import/0.1`。檔案照原樣存放，沒有人工修改。
- 匯入：`uv run python -m app.cli load-calendar`（`dev.ps1` 每次啟動都會跑，可重跑）。

| 檔案 | 原始檔名 | 資料集上的檔案 | 下載日期 | 編碼 |
|---|---|---|---|---|
| 2025.csv | 114年中華民國政府行政機關辦公日曆表(1141020更新).csv | dgpa/files/202510/b84cb88a-803c-4621-a843-d637b2775615.csv | 2026-11-24 | Big5（cp950） |
| 2026.csv | 115年中華民國政府行政機關辦公日曆表.csv | dgpa/files/202506/a52331bd-a189-466b-b0f0-cae3062bbf74.csv | 2026-11-24 | UTF-8（含 BOM） |
| 2027.csv | 116年中華民國政府行政機關辦公日曆表_utf8bom.csv | dgpa/files/202607/f538b1ff-ba60-4c63-9477-10db8e6612d1.csv | 2026-11-24 | UTF-8（含 BOM） |

欄位：`西元日期`（yyyymmdd）、`星期`、`是否放假`（`0` 上班、`2` 放假）、`備註`（例如「開國紀念日」「補行上班」）。

注意：

- 颱風等臨時停止上班不在這份資料內，試算結果會提醒律師自行確認。
- 2028 年以後的檔案公布前，超出範圍的日期只順延週末，並在試算結果標示「行事曆資料未涵蓋，只順延週末」。

## 尾數核對

上訴、抗告加徵十分之五後，可能算出 0.5 元。目前程式四捨五入到元，並標示「尾數處理以法院通知為準」。

2026-11-24 用網路搜尋找補繳第二審裁判費的裁定，沒有找到費額剛好出現 0.5 元、並寫明怎麼處理尾數的實例。找到的裁定只有把利息計算的元以下四捨五入（例：臺灣臺北地方法院 114 年度重訴字第 772 號裁定）。

**未找到實例，列入待律師審定。**

搜尋時也看到另一則摘要，提到臺灣高等法院的「提高徵收額數標準」自 2025-01-01 起有新版。目前程式的級距是：

- 10 萬元以下加徵十分之五；
- 逾 10 萬元至 1,000 萬元加徵十分之三；
- 逾 1,000 萬元加徵十分之一。

逾 1,000 萬元的部分是否有變動，也列入待律師審定。
